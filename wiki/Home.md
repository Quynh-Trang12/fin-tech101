# FinTech101 Wiki

## Project Background

FinTech101 is a stock price prediction system built for **COS30018 – Intelligent Systems (Project Option C)**. The project began from a single-file baseline (v0.1) and a reference implementation (P1), and was progressively rebuilt into a modular machine learning framework covering data processing, deep learning forecasting, statistical-deep learning hybrids, and sentiment-based classification.

The system forecasts the price of Commonwealth Bank of Australia (CBA.AX) using historical market data, and — in its Task C.7 extension — predicts next-day price direction using financial news sentiment in addition to market data.

---

## Scope

This Wiki holds all documentation for the project, as required by Task C.1: architecture references, the experiment pipeline, task-to-implementation traceability, and the weekly reports submitted for each task. Implementation detail that belongs in a single task's report stays in that report; pages here describe the system as a whole.
